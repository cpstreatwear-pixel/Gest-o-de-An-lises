# BI — Gestão de Análises

## Sobre o projeto

Projeto de Business Intelligence desenvolvido com foco na gestão de análises laboratoriais e no acompanhamento de indicadores de controle de qualidade industrial.

A proposta é centralizar informações, facilitar a interpretação dos resultados analíticos e auxiliar na identificação de desvios, proporcionando maior visibilidade sobre os processos monitorados.

## Objetivos

- Centralizar informações relacionadas às análises.
- Facilitar o acompanhamento dos resultados.
- Identificar desvios e tendências.
- Otimizar a consulta de informações.
- Auxiliar na tomada de decisão.
- Reduzir a necessidade de controles manuais.

## Tecnologias utilizadas

- Microsoft Power BI
- Power Query
- DAX
- Google Sheets
- Microsoft Excel

## Desenvolvimento do projeto

- Estruturação e padronização das bases de dados.
- Tratamento e transformação de informações.
- Modelagem relacional de dados.
- Desenvolvimento de medidas e indicadores.
- Construção de dashboards interativos.
- Estruturação de filtros e recursos de navegação.
